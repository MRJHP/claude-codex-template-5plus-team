# 코드 오너십

팀원별 담당 영역을 기록한다. 새 팀원이 합류하거나 담당이 바뀌면 이 표와
[.github/CODEOWNERS](../../.github/CODEOWNERS)를 함께 갱신한다.

`/init` 스킬로 이 템플릿을 초기화할 때 실제 팀 구성으로 채운다.
아직 팀원이 다 정해지지 않아, 현재는 `@MRJHP`가 전체 경로의 기본 오너로 지정되어 있다
(`.github/CODEOWNERS`). 팀원이 합류하면 아래 표와 CODEOWNERS를 모듈별로 세분화한다.

| 영역 | 담당자 | GitHub 핸들 | 비고 |
|---|---|---|---|
| 전체 (기본 오너) | - | @MRJHP | 팀원 합류 전까지 임시 지정, 모듈별로 세분화 예정 |
| `src/...` (예시) | (이름) | @handle | |
| `.github/`, CI/CD | (이름) | @handle | |

## 담당 범위 밖 변경 시

- 담당 모듈을 벗어난 변경이 필요하면, PR 생성 전에 담당자와 짧게 동기화한다
  ([team-collaboration.md](../rules/team-collaboration.md) 참고).
- 여러 모듈에 걸친 변경은 가능하면 PR을 모듈별로 나눈다.
- 담당자가 명확하지 않은 영역은 이 표에 먼저 추가하고 팀과 합의한다.
